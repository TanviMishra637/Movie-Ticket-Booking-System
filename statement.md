# Statement of the Movie Ticket Booking System

## 1. Problem Statement

Booking movie tickets manually can require users to go to the theatres and check movie details, ticket prices, seat availability, and food options separately. A simple computerized system can combine these activities into one program.

The Movie Ticket Booking System is designed to provide a basic console-based solution where a user can select a movie, view its ticket price and seat arrangement, book available seats, and optionally order snacks. The system then calculates the ticket cost, snack cost, and generates a  final bill.

## 2. Scope of the Project

The project covers the basic movie ticket booking process which includes the following features

- Movie selection.
- Display of ticket prices.
- Seat arrangement display.
- Seat selection and booking.
- Ticket price calculation.
- Snack selection.
- Snack quantity handling.
- Snack price calculation.
- Final bill calculation.

The current scope does not include online payment, user authentication, database storage, cancellation/refund processing, or a graphical user interface.

## 3. Target Users

The intended users are:
- People who want to book movie tickets through a simple application.
- Students learning Python programming and software development concepts.
- Users who need a basic demonstration of a movie booking workflow.

## 4. High-Level Features

1. **Movie Selection**  
   The user can choose from five available movies.

2. **Ticket Pricing**  
   Each movie has a predefined ticket price.

3. **Seat Arrangement**  
   The system displays the theatre seat arrangement.

4. **Seat Booking**  
   Users can enter seat IDs and book available seats.

5. **Ticket Calculation**  
   The system calculates the total cost based on the number of tickets.

6. **Snack Ordering**  
   Users can optionally order snacks using predefined order IDs.

7. **Bill Calculation**  
   The system adds the ticket and snack costs and displays the final bill.
